# invest_tops

'What if you bought at the very top?' crash-recovery app on Shiller data.

**Run:** `streamlit run app.py`  
**Rebuild env (if no venv):** `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt` (requirements.lock.txt = exact pins from the old venv, may not build on newer Python)
